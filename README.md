# 🚀 Getting Started

## 1️⃣ Clone Repository

```bash
git clone YOUR_GITHUB_REPO_LINK
cd spendsmart
```

---

## 2️⃣ Install Dependencies

```bash
npm install
```

---

## 3️⃣ Run Development Server

```bash
npm run dev
```

App will run on:

```bash
http://localhost:5173
```
